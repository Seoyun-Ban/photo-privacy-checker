# 서비스: SNS 업로드 전 사진 개인정보 검사기

## 문제
SNS에 사진을 올릴 때 얼굴 외에도 간판, 송장, 교복, 반사된 화면처럼
조합하면 위치·신원이 드러나는 단서를 사람들이 놓친다.
기존 앱은 얼굴 모자이크만 한다.

## 핵심 기능
1. 사진 업로드
2. 메타데이터(GPS 등) 검사 - 코드로 처리
3. AI가 사진 속 단서 분석 - 위치/신원/번호·문서/생활패턴/타인/반사
4. 결과: 종합 위험도 + 항목별 위험 요소, 이유, 수정 방법
5. (추가) 위험 부분 자동 모자이크

## analyze 함수 형식 (app.py와 analyzer.py의 약속)
analyze(image_bytes) -> {
  "overall": "낮음" | "주의" | "높음",
  "risks": [
    {"category": "위치", "item": "창밖 간판", "reason": "...", "severity": 1~3, "fix": "..."}
  ]
}
- overall은 severity를 바탕으로 코드에서 계산

## 표현 원칙
- 단정하지 말고 "~로 유추될 수 있습니다"처럼 가능성과 근거로 표현
- 분석한 사진은 저장하지 않음
