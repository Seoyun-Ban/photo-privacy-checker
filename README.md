# 📸 Photo Privacy Checker

> **올리기 전, 사진 속 숨은 개인정보를 AI가 찾아 주고 안전하게 가려 주는 서비스**

SNS에 사진을 올릴 때 얼굴은 신경 쓰지만, 택배 송장 속 이름, 창밖 간판, 교복, 거울에 비친 화면처럼
**조합하면 위치나 신원이 드러나는 단서**는 놓치기 쉽습니다.
이 서비스는 사진을 분석해 그런 단서를 찾고, 왜 위험한지 설명하고, 사용자가 직접 다듬어 가린 뒤 바로 공유할 수 있게 해 줍니다.

🔗 **배포 주소**: https://photo-privacy-checher-6jgd26xsjhrl56hczqvdku.streamlit.app/

---

## 🧩 해결하려는 문제

- 개인정보 보호 캠페인은 "올리기 전에 개인정보가 있는지 확인하라"고 안내하지만, **무엇을 확인해야 하는지는 개인에게 맡겨져** 있습니다.
- 기존 도구는 얼굴이나 위치 정보처럼 **정해진 대상만** 가립니다.
- 특히 혼자 사는 20대 자취생의 택배·방·창밖 사진은 **집의 위치를 알려 주는 단서**가 되기 쉽습니다.

## ✨ 주요 기능

| 단계 | 기능 |
|---|---|
| ① 검사 | 사진 속 **EXIF 메타데이터(GPS)** 검사 + AI가 사진 내용의 단서 분석 |
| ② 확인 | 종합 위험도(낮음/주의/높음)와 항목별 **이유·수정 방법** 제시 |
| ③ 가리기 | AI가 찾은 위치에 자동으로 영역 표시 → 사용자가 **이동·크기 조절·추가**, 모자이크/블러 **강도 5단계** 조절 |
| ④ 재검사 | 가린 수정본을 **다시 분석**해 남은 위험 확인 |
| ⑤ 공유 | 위험 요소를 가린 뒤에만 **공유 버튼 활성화** → 모바일에서 인스타그램·카카오톡 등으로 공유, 미지원 환경은 다운로드 |

AI가 찾는 단서 범주: **위치 · 신원 · 번호·문서 · 생활패턴 · 타인 · 반사**

## 🏗️ 설계 원칙

- **AI는 판단과 설명, 코드는 계산** — GPS 검사와 위험도 계산은 코드로 정확하게, 단서 판단과 설명은 AI가 담당
- **AI가 제안하고, 최종 결정은 사용자가** — AI 좌표는 대략적일 수 있으므로 사용자가 직접 조정 가능
- **단정하지 않는 표현** — "~로 유추될 수 있습니다"처럼 근거와 가능성으로 안내

```
사진 업로드
   ├─ [코드] EXIF GPS 검사
   └─ [AI] Gemini 멀티모달 분석 → 위험 요소 + 바운딩 박스(0~1000 정규화 좌표)
           ↓
   [코드] 위험도 계산 · 좌표 변환 · 해시 기반 캐싱
           ↓
   [화면] 편집기에서 영역 조정 → 모자이크/블러 → 재검사 · 다운로드 · 공유
```

## 🛠️ 기술 스택

- **Python**, **Streamlit** (화면, 사진 위 편집 컴포넌트)
- **Gemini API** (멀티모달 사진 분석)
- **Pillow** (EXIF 메타데이터, 모자이크·블러 처리)
- **Kiro** (AI 기반 개발 — steering 파일로 팀 공통 규칙을 정해 3명이 병렬 개발)

## 🚀 실행 방법

```bash
pip install -r requirements.txt
```

프로젝트 폴더에 `.env` 파일을 만들고 키를 넣습니다.

```
GEMINI_API_KEY=발급받은키
```

```bash
python -m streamlit run app.py
```

> API 키는 [Google AI Studio](https://aistudio.google.com)에서 발급할 수 있습니다. `.env`는 `.gitignore`에 포함되어 있어 저장소에 올라가지 않습니다.

## ⚠️ 한계와 개선 방향

- 분석에 수십 초가 걸릴 수 있음 → 경량 모델, 이미지 최적화로 개선 예정
- 아주 작은 글씨나 흐린 단서는 놓칠 수 있음 → 사용자 편집과 재검사로 보완
- 현재는 분석을 위해 사진이 외부 AI 서버로 전송됨 (분석 사진은 저장하지 않음)
  → **기기 내(on-device) AI 처리**로 사진이 밖으로 나가지 않도록 하는 것이 목표
